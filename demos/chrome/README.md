# Chrome Demo：打开网址

## 示范任务

从 Chrome 未运行或已有窗口的状态出发，打开指定的 `https://` URL，并证明地址栏最终指向目标页面。

## 建议录制

1. 基准：Chrome 未运行，双击/启动后打开 `https://example.com`；
2. 变化：Chrome 已运行、窗口移动并缩放后，打开另一个 URL；
3. 异常：断网或页面加载失败时，区分“地址已导航”和“页面已成功加载”。

每次录制开始前由操作者明确标记任务起点，结束时标记成功或失败。不要录制包含登录令牌的 URL。

## 验收条件

- 不依赖固定屏幕坐标；
- 中英文 Chrome 至少能通过快捷键路径工作；
- Chrome 未启动和已启动两种状态都能处理；
- 兼容动作档案输入 URL 被日志遮蔽；
- 地址栏值或等价浏览器状态能够证明导航结果。

草案档案：`profiles/chrome/open-url.action-profile.json`。
