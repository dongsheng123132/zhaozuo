# WPS Demo：新建并保存文档

## 示范任务

打开 WPS 文字，新建空白文档，输入一段测试正文，并保存到专用测试目录中的新文件。

## 开始前

本机已发现：

- 当前注册版本：`12.1.0.26895`；
- 当前候选：`%LOCALAPPDATA%/Kingsoft/WPS Office/12.1.0.26895/office6/wps.exe`；
- 残留旧版：`12.1.0.25865`。

因此第一次录制前必须确认：

- 实际启动进程来自 12.1.0.26895，而不是残留旧版；
- 首页与编辑器窗口的 UIA 控件树；
- 系统“另存为”对话框的控件名称与 Automation ID；
- 测试目录为空且可以恢复。

## 建议录制

1. 基准：WPS 未运行，创建 `demo-1.docx`；
2. 变化：WPS 已在首页或已有文档中，创建 `demo-2.docx`；
3. 异常：目标文件已存在，确认执行器拒绝静默覆盖。

## 验收条件

- 正文不会出现在录制日志和 Git 中；
- 不依赖窗口绝对位置；
- 保存前确认目标路径，默认拒绝覆盖；
- 执行后检查文件存在、大小大于 0，并在后续阶段验证文档内容摘要；
- 失败后能关闭测试文档或保留现场，不污染真实文档。

草案档案：`profiles/wps/create-document.action-profile.json`。
